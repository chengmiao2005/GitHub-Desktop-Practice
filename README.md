# GitHub Desktop Practice

A small repository for learning the edit, review, commit and push workflow with GitHub Desktop. GitHub Desktop 基础操作练习。

Former repository name: `desktop-tutorial`.

## Practice workflow

1. Clone the repository and open its local folder.
2. Make a small, meaningful change to this README and save it.
3. Review the diff in GitHub Desktop.
4. Commit with a message describing the change.
5. Push the commit and check the updated file on GitHub.

This repository contains documentation only; there is no application to build or run.
